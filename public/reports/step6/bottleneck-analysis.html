Topic 03

执行瓶颈分析

严格区分真正的 Agent/API 阻塞与普通执行低效，避免把“耗时较长”直接等同于“挂死”。

本轮判断

现有摘要没有确认 Agent 挂死或 API 卡死；已确认的主要瓶颈类型是反复搜索、错误定位和 DAO 路径试错造成的执行低效。

判定阈值

120 秒Agent 无新事件阈值
60 秒API 未返回阈值
成功返回超过 60 秒记为 API 慢调用
排除build/test、本地脚本、明确等待
Agent 挂死
Session 仍在执行、不处于工具调用期间，连续 120 秒没有 request、response、tool call 或 tool result 等新事件。
API 卡死
外部 API 调用超过 60 秒仍未返回，或最终以 timeout/cancelled 结束。
API 慢调用
外部 API 调用超过 60 秒但最终成功返回；单独统计，不记为卡死。
执行低效
反复搜索、错误定位、重复尝试和不必要路径探索；可能耗时很长，但不是进程或 API 阻塞。
